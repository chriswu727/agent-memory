AGENT MEMORY · RESEARCH NOTE · 2026-10-23

From Tiered Storage to Situated Memory and Learning

A focused review of 25 cognitive-science and agent-memory papers, with concrete recommendations for the existing architecture. Research inspiration, engineering choices, and effects awaiting validation are stated separately.

Research conclusions and scope

The existing architecture already proposes episodes, semantic beliefs, procedural memory, a workspace, and stratified forgetting. This review clarifies how they should cooperate around the current situation, structure across episodes, conditional regularities, and recoverable concrete evidence. Scoring each record's importance and reducing its weight over time is not sufficient.

Functionally human-like memory includes past experience naturally shaping the current response; the same cue retrieving different experiences in different situations; knowing some facts years later without reconstructing a specific scene; and new information changing understanding without rewriting what originally happened.

Status: This report contains research and design recommendations, not implemented capabilities. The code baseline is 84b4a74. This work did not modify the runtime, run real-model quality experiments, enable automatic detail erasure, or run cloud CI.

The method was a focused literature search around project questions, covering original human experiments, theoretical reviews, computational models, and recent agent systems. It was not a preregistered systematic review or a meta-analysis. Available full texts were checked for mechanisms, experimental settings, and limitations; entries available only as abstracts are identified below. Paper counts, neuroscience terminology, and public leaderboard scores do not prove our system works.

“Brain-inspired” here means functional engineering inspiration. External memory can alter the inputs and behavior of a frozen model API, but this does not establish weight learning or human-like subjective experience. Preserve source monitoring and correction without deliberately reproducing human defects such as false recall or misattribution.

Nine mechanisms to make concrete

1. Organize experiences by situation and goals

Natural-narrative research finds event segmentation at multiple timescales. A 2025 VR experiment further shows that transitions in task meaning affect temporal-order memory within that task. Engineering should use changes in goals, participants, and problem state as segmentation signals, allowing multiple granularities and overlapping boundaries. Baldassano et al., 2017; Li et al., 2025.

Design: Reliably store original messages first. The current situation tracks what is happening, who participates, and what remains unresolved. Meaningful topic or goal changes close or revise an Episode. An Episode is a revisable, grounded projection, not another uncorrectable factual record. Time windows serve only as supporting boundary signals and resource limits.

Add overlapping indexes for project phases, relationship phases, and life periods so “during exam preparation” can locate a group of experiences. Autobiographical-memory theory inspires this organization, but childhood described by a user remains a user report rather than an experience the agent lived. Conway and Pleydell-Pearce, 2000.

2. Preserve specific experiences alongside generalized beliefs

Human studies support the role of existing schemas in organizing new memories and semantic transformation in some memories over time. These findings do not imply that all details disappear at one rate. Our layers should allow generalizations, relations, fragments, and source text to be retained and retrieved independently. Audrain and McAndrews, 2022; Krenz et al., 2023.

Design: An Episode may produce a semantic belief but must not be replaced by it. Every belief includes applicability, valid time, supporting sources, counterexamples, and an interpretation version. “I know you attended that primary school” and “I can recall the graduation day you described” have different evidence requirements. Higher-level generalizations are retrieval entry points, not the only route to deeper evidence.

3. Represent memories through shared patterns and individual differences

Two generative computational memory models suggest a useful compression idea: shared generalizations explain repeated structure while individual experiences retain unexpected details. These are model-based explanations, not established complete algorithms of the human brain. Spens and Burgess, 2024; Spens and Burgess, 2026.

Design: A compact view can contain a pattern reference and version, instance differences, and necessary source locations. Repeated exam-preparation conversations may share “relax before planning,” while an instance explicitly requesting immediate planning retains that exception. Old episodes remain bound to their original pattern version when the pattern changes. Expand sources for precise answers. Unsupported gaps remain gaps.

The 2026 model includes learned compressed representations and training. Supplying a vector to an arbitrary Chat Completions API does not establish recovery of an entire history. Our general implementation should begin with readable structured text and measure compression benefits, omission rates, and expansion costs together.

4. Separate situational differences, temporal changes, and exceptions

Multiple-schema learning experiments suggest that several situational models may be preferable to combining every experience into one model. Computational work on selective consolidation emphasizes distinguishing predictable shared structure from instances that should not generalize. Beukers et al., 2024; Sun et al., 2023.

Design: “Give direct advice during work discussions” and “Listen first when I am upset” can both be valid. “Give me solutions directly from now on” may be an explicit update; “Do not comfort me today” may be one exception. Evidence determines whether to add a situation, narrow applicability, record an exception, or publish a replacement version. Preserve ambiguity when evidence is insufficient instead of forcing one belief to override another.

Surprise only triggers review. A model's unmet expectation does not mean the user is wrong or justify assigning the user a stable personality label.

5. Reinstate the situation before seeking specific content

Context-dependent memory research and recent reinstatement experiments support a limited conclusion: suitable cues can make some temporarily inaccessible content easier to recall, under particular conditions, with forgetting continuing afterward. They do not imply all forgetting is reversible. Godden and Baddeley, 1975; Bäuml et al., 2025.

Design: “After the exam went badly” first matches a period, goal, or event; then the system reads related people, surrounding events, and fragments, and searches again with newly found cues. The controller can bypass generalizations and search source text directly, deciding within budget whether to continue, answer the known portion, or ask for a discriminating cue.

All recovery stays within the previously readable historical evidence scope. “We once went to the beach together” in the current question is a cue, not proof that old records contain such an event. Preserve ambiguity between people sharing names, similar events, and branches; associations must not spread without bounds.

6. Adjust accessibility by future utility and protect weak but useful memories

Research on environmental statistics and memory links frequency, recency, and occurrence patterns to future need. Retrieval-practice research also finds that strengthening selected content can accompany difficulty retrieving related content, highlighting candidate competition. Anderson and Schooler, 1991; Anderson et al., 1994.

Design: Current goals, situation match, distinctiveness, external use history, and time influence accessibility. Protect future commitments and rare but important exceptions. Candidate deduplication, event diversity, and direct lookup prevent frequently used generalizations from monopolizing context. Task evaluation determines functions and parameters; do not assume a universal human forgetting constant.

Store retrieval priority, retention value, evidence state, factual validity, and detail availability separately. Background self-retrieval and model restatement cannot increase independent evidence; familiarity from repetition is not reliable knowledge. Speckmann and Unkelbach, 2024.

7. Improve understanding through selective review while preserving history

Spacing and retrieval practice are widely studied in human learning. Experiments on prediction error and updating show that subsequent information can affect recall under some conditions. These findings can inspire review triggers, not justify automatically rewriting original events. Carpenter et al., 2022; Sinclair and Barense, 2018.

Design: Background work prioritizes new events, contrary evidence, failed retrieval, unfinished tasks, and outdated methods. Jobs read actual sources, seek counterexamples, revise associations or generalizations, and validate versions and dependencies before publication. Activation decay without semantic change needs no model call. Repeated reflection without new evidence cannot increase credibility. Periodic samples can test retrievability of valuable memories without rereading the entire database.

For a frozen API, review improves external structure and the next input, not base-model weights. Jobs need queue deduplication, computation budgets, retry boundaries, and cumulative cost records. Background processing is not free.

8. Make the system recognize its knowledge and gaps

Source-monitoring research and memory-report control research emphasize provenance and reporting choices respectively. Engineering should translate these into observable evidence states and action selection rather than asking a model for a subjective confidence percentage. Johnson et al., 1993; Koriat and Goldsmith, 1996.

Design: Before answering, distinguish support by a generalization, a specific source, multiple candidates, conflict, no match in this search, and unavailable sources. Retrieval scope, indexing progress, versions, and budgets provide the basis. If only a school name is found, answer that; without a graduation-ceremony source, do not present plausible imagination as memory. Permit further search and clarification while measuring unnecessary refusals.

9. Let experience change how problems are handled

Memory should inform future planning and actual behavior. Constructive-memory theory connects past experience with future imagination; recent procedural agent-memory work attempts to form methods from execution traces. Neither means that imagining an event is the same as experiencing it. Schacter and Addis, 2007; Memp, 2026 version.

Design: A method includes applicability, steps, failure conditions, environment version, actual attempts, and outcomes. Observable feedback is required to support effectiveness; model self-assessment is only a cue for review. Record future simulations separately from actual execution and manage commitments separately from action authorization. This moves an agent from stored conversations toward behavior that changes through experience.

How an experience gradually becomes usable understanding

During exam preparation, a user says, “I feel awful tonight. Talk with me first, and help plan revision in ten minutes.” The system reliably stores that expression, keeps the pending planning in the current workspace, and associates it with this exam-preparation episode. This establishes the current request, not a permanent dislike of advice.

If multiple independent expressions later support it, form a conditional belief: “When discouraged during exam preparation, the user tends to prefer conversation before task planning.” Another request, “Give me the plan directly today,” may override the current instance or form an exception. Whether it changes a lasting preference depends on the wording and later evidence. Statistical inference must not override the explicit request's scope.

A year later, ordinary conversation need not carry these details. “It is another evening when I cannot study” can reactivate the belief through the current situation and shape the response. Only “How long did we agree to talk?” requires expansion of the retained specific source. A generalization without the original wording cannot supply “ten minutes.”

For primary-school memories, the evidence remains experiences reported by the user. School names, important people, and a few distinctive scenes may be retained for years, while ordinary details become harder to recall spontaneously. A separate retention policy determines whether deep source text still exists. Cues cannot recover more than the evidence actually retained and authorized for use.

Where these mechanisms fit in the existing runtime

Input and actual outcomes→Current situation→Search and expansion→Bounded workspace→Response or action→New experience and local consolidation

Retain one domain core, one PostgreSQL authoritative/version store, rebuildable retrieval projections, and independent workers. New cognitive responsibilities do not require a service for every concept. The server continues enforcing provenance checks, authorization, corrections, and deletion for every derived output.

These descriptions refer to the code baseline. A “semantic recall controller” can ask a model to understand a query and select candidates; it does not mean semantic vector retrieval, semantic consolidation, or event understanding already exists underneath. Safe runtime recovery and long-term memory quality are different validation questions.

Code review identified three prerequisites. Current work_once() performs deterministic processing inside a database transaction; before slow model integration, it needs short transaction claims, computation outside the transaction, revalidation before publication, leases, and cognitive cost accounting. Current recent_event_refs accepts only this conversation and branch; cross-episode expansion needs independent source references. Ordinary events still have origin_verification set to unknown; trusted tool outcomes must be integrated before procedural learning. A result type in a contract alone does not establish a working feedback loop.

  Source spans, boundary version, situation, time range, granularity, detail availability

  Conditional beliefs, valid time, independent support, counterexamples, interpretation version

  Accessibility, external use history, candidate coverage, cost, stopping reason

These objects can be versioned projections over existing tables; there is no need to invent a vast class hierarchy first. Check confidence in a derived structure separately from source existence: a valid reference does not establish semantic support for a new generalization.

Recent agent papers offer comparable implementation routes: ES-Mem for event segmentation, TiMem for temporal hierarchical expansion, LightMem for offline batching, FluxMem for connection updates, Memp for procedural memory, and MemRL for utility feedback. They solve different problems and cannot simply be assembled because their names contain “memory.” Measure every introduced mechanism's benefit under the same budget. ES-Mem, TiMem, LightMem, FluxMem, Memp, MemRL.

Full integration still requires the host to prepare memory automatically before inference, commit after actual outcomes, and recover stable identity and working state. MCP can provide supplementary exploration, but tools alone cannot guarantee that the primary agent spontaneously completes a memory cycle. State compatibility boundaries for closed applications without lifecycle access.

Bounded context, unlimited detail, perfect answers to arbitrary historical questions, and fixed read cost cannot all be guaranteed. Default cognitive fading may retain source text, but external storage still grows. Measurements must include background processing and deep expansion; retention and cognitive accessibility require separate policies.

How to establish that these mechanisms are worthwhile

The following experiments were designed, not run during this review. Simulated time can validate decay and version rules; it does not replace real-model testing or establish quality after decades of actual use.

  1. Segmentation: Under the same answering budget, compare fixed windows, conversation boundaries, and goal/event boundaries. Measure missed cross-boundary evidence, segmentation cost, and final answers rather than optimizing segmentation labels alone.
  2. Shared patterns and individual differences: Compare hybrid source retrieval, a single summary, multiple granularities, and patterns plus differences. Check preservation of negation, roles, conditions, exceptions, and key wording, and measure total storage and expansion costs.
  3. Context reinstatement: Use direct, implicit, vague, and false-premise cues against the same historical snapshot. Measure genuinely new evidence, ambiguity handling, and unsupported recall. The current cue and derivatives must not enter the historical proof set.
  4. Belief change: Separately test coexisting situations, explicit temporal changes, one-off exceptions, user corrections, and withdrawn evidence. Check current and historical queries; “most recent occurrence” is not a universal resolution rule.
  5. Forgetting and competition: Advance simulated time by 3, 30, 365 days and add many similar events. Check retrieval of valuable specific fragments, rare exceptions, and unfinished commitments. Compare coverage with and without diversity constraints on strong candidates.
  6. Self-reinforcement: Internally restate one independently unsupported claim 1, 5, and 50 times. Independent evidence count and truthfulness must not increase. Cache hits and background review are not external confirmation.
  7. Metamemory: Mix complete, partial, conflicting, missing, backlogged, and failed evidence states. Measure error rate, answer coverage, clarification count, and extra reads together so universal refusal cannot manufacture high accuracy.
  8. Procedural learning: Evaluate methods on new tasks using independent actual outcomes, with environment changes and failure counterexamples. Model self-assessment is not the sole success label.
  9. System constraints: Check every new projection for deletion, correction, scope isolation, concurrency, restart recovery, and exhausted budgets. After source deletion, individual differences, patterns, indexes, and caches must not provide a bypass.

Fix the answering model, data order, and total budget for ablations. Split development and test data by whole histories to prevent paraphrase leakage from the same experience. Account uniformly for encoding, embeddings, consolidation, retrieval planning, reranking, context, final generation, and storage. Real model-call spending requires user authorization; this report contains no effectiveness figures.

The complete behavior chain proposed for priority implementation is event formation → conditional beliefs and exceptions → situated recall → grounded workspace → outcome feedback and local revision. This is a causal dependency order, not a demo-release sequence. There is no evidence that a neuron simulator, a full reinforcement-learning platform, or a separate graph database must come first.

25 papers: findings, evidence types, and boundaries

Years refer to formal publication or the cited preprint version. Full-text checking means examining the text and limitations relevant to this report's claims, not reproducing the study line by line. This project has not reproduced the papers' results.

01 · Conway & Pleydell-Pearce · 2000

The construction of autobiographical memories in the self-memory system

Theoretical review; abstract and retrieved excerpts of the authors' full text. Lifetime periods, general events, and event-specific knowledge organize autobiographical recall together with current goals. This inspires multiscale, overlapping episode indexes; it does not establish that this database structure was validated in human experiments.

02 · Baldassano et al. · 2017

Discovering event structure in continuous narrative perception and memory

Human narrative experiments and fMRI; full text. Event structure at different timescales and boundary-related activity are associated with memory reinstatement. This supports investigating event boundaries; brief narrative experiments do not directly establish an implementation of years-long autobiographical memory.

03 · Li, Johansson & Nikolaev · 2025

Hierarchical event segmentation of episodic memory in virtual reality

VR experiment with 26 participants; search results from the original full text. Conceptual task boundaries affected temporal-order accuracy more strongly than spatial boundaries in this task. This supports incorporating goal changes, not a universal advantage of goal cues over spatial cues.

04 · Anderson & Schooler · 1991

Reflections of the Environment in Memory

Environmental statistics and rational analysis; original journal abstract and retrieved paper content. Frequency, recency, and occurrence patterns relate to future need. This inspires utility estimation but provides no universal decay parameters for every user and content type.

05 · Johnson, Hashtroudi & Lindsay · 1993

Source monitoring

Framework review; abstract. Examines how people judge the sources of knowledge and make errors. It inspires explicit source types for reports, observations, inferences, and imagination. The abstract does not support detailed claims about experimental effects.

06 · Sinclair & Barense · 2018

Surprise and destabilize: prediction error influences episodic memory reconsolidation

Human video-memory experiments; full text. Unexpected incomplete reminders relate to subsequent interference and memory updating, subject to timing conditions. This can inspire local review triggers, not a rule that every retrieval rewrites memory.

07 · Schacter & Addis · 2007

The cognitive neuroscience of constructive memory: remembering the past and imagining the future

Theoretical review; full text. Flexible recombination of past details relates to imagining the future. This inspires experience-informed planning, while historical statements and simulated outcomes still require distinct evidence status.

08 · Audrain & McAndrews · 2022

Schemas provide a scaffold for neocortical integration of new memories over time

Human behavior and fMRI at 10 minutes and 72 hours; full text. Schema-consistent information more readily shows organized integration alongside changes in detail. This does not require every new event to fit an existing schema or turn imaging associations into causal proof of transfer.

09 · Krenz et al. · 2023

Time-dependent memory transformation in hippocampus and neocortex is semantic in nature

Human behavior and fMRI at 1 or 28 days; full text. Longer-term changes in this experiment fit semantic transformation better than mere blurring of perceptual detail. This inspires meaning- and relation-preserving generalization, not a universal trajectory for every life experience.

10 · Sun et al. · 2023

Organizing memories for generalization in complementary learning systems

Go-CLS mathematical and neural-network models; full text. Selective consolidation by predictable structure can improve model generalization, while indiscriminate transfer may overfit. This inspires management of support and counterexamples; it does not directly validate the policy in biological brains or this product.

11 · Beukers et al. · 2024

Blocked training facilitates learning of multiple schemas

Human narrative experiments and a computational model; full text. Blocked training helped learning of multiple schemas in the studied tasks. The model explanation involves splitting representations after larger prediction errors. This does not mean blocked training always outperforms interleaving.

12 · Spens & Burgess · 2024

A generative model of memory construction and consolidation

Computational model; full text. Fast associative storage and a generative network trained through replay explain specific and conceptual memories and some biases. This supports studying experiences and generalizations separately, not equating the human brain with the network.

13 · Spens & Burgess · 2026

Hippocampo-neocortical interaction as compressive retrieval-augmented generation

Computational model; published 2026-06-25; full text. Combines compressed generalizations, unexpected details, retrieval, and generation. Event segmentation and retrieval timing are preset, some decay is unmodeled, and compressed representations require training. General APIs may borrow organizational principles without inheriting the model's compression capability.

14 · Godden & Baddeley · 1975

Context-dependent memory in two natural environments: On land and underwater

Word-list experiment with human divers; original journal abstract and index. Matching learning and recall contexts can help retrieval. The narrow task does not establish that arbitrary emotion or environment fields improve AI memory.

15 · Bäuml, Meixensperger & Hirsch · 2025

Reinstating memories’ temporal context at encoding causes Sisyphus-like memory rejuvenation

Two human experiments, 1,216 participants in total; full text. Context reinstatement or selective retrieval improved recall at 4 and 24 hours; the direct comparison at 7 days was not significant, and forgetting continued. Some recovery proportions are model estimates; the study does not show that every detail remains intact.

16 · Anderson, Bjork & Bjork · 1994

Remembering Can Cause Forgetting: Retrieval Dynamics in Long-Term Memory

Three human experiments; original abstract and retrieved paper content. Practicing retrieval of selected items made some related, unpracticed items harder to retrieve. Not all associations deteriorate. Engineering should mitigate competition, not use this as a reason to delete unused memories.

17 · Carpenter, Pan & Butler · 2022

The science of effective learning with spacing and retrieval practice

Review of human learning; full accepted manuscript. Discusses spacing, retrieval practice, and their conditions. It can inspire bounded review, but rereading an external database is not learning in a frozen model; sources and feedback still require checking.

18 · Koriat & Goldsmith · 1996

Monitoring and Control Processes in the Strategic Regulation of Memory Accuracy

Human experiments and theoretical model; abstract. Choice about reporting helps regulate accuracy and quantity, depending on monitoring and conditions. This motivates evaluating answer coverage alongside errors, not treating model self-confidence as calibrated probability.

19 · Speckmann & Unkelbach · 2024

Illusions of knowledge due to mere repetition

Four preregistered human experiments, 773 participants in total; abstract and authors' full text. Repetition affects judgments of prior knowledge and source attribution. This does not mean repetition always makes falsehoods seem true; engineering should separate familiarity from independent evidence.

20 · ES-Mem · 2026 · v2

ES-Mem: Event Segmentation-Based Memory for Long-Term Dialogue Agents

Agent system and benchmark experiments; full 2026-01-13 version. Combines topic continuity and local intent for segmentation, preserving boundaries, summaries, and source text with post-retrieval expansion. Evaluated on LoCoMo, LongMemEval-S, and other benchmarks; this project must validate Chinese conversational language, cross-session boundaries, and resource costs.

21 · TiMem · 2026 · v2

TiMem: Temporal-Hierarchical Memory Consolidation for Long-Horizon Conversational Agents

Agent system and benchmark experiments; full 2026-04-30 version. Uses temporal hierarchies and granularity selection by query complexity, evaluated on LoCoMo and LongMemEval-S. This inspires on-demand expansion; fixed calendar hierarchies are not actual event structure and do not resolve every storage-forgetting issue.

22 · FluxMem · 2026 · v1

Rethinking Memory as Continuously Evolving Connectivity

Ongoing agent-research preprint; full 2026-05-27 version. Heterogeneous connections, activation, and feedback updates, with reported LoCoMo, Mind2Web, and GAIA experiments. Some feedback relies on self-verification; our system cannot promote model self-assessment to independent outcome evidence.

23 · Memp · 2025 / 2026 · v4

Exploring Agent Procedural Memory

Agent procedural memory and benchmark experiments; full 2026-04-15 version. Builds, retrieves, validates, and updates methods from execution traces and abstract scripts using TravelPlanner and ALFWorld. Their relatively explicit task outcomes do not directly define success in open-ended companionship.

24 · LightMem · 2025 / 2026 · v4

LightMem: Lightweight and Efficient Memory-Augmented Generation

Agent-memory and efficiency experiments; full 2026-02-28 version. Preprocessing, topic organization, threshold-based batching, and offline updates evaluated on long-term memory benchmarks. This inspires budgeted background work; the paper's accounting boundaries do not equal the complete product's end-to-end cost.

25 · MemRL · 2026 · v2

MemRL: Self-Evolving Agents via Runtime Reinforcement Learning on Episodic Memory

Memory utility learning with a fixed model; full 2026-02-12 version. Filters semantically relevant candidates before learning utility from feedback, with evaluation on multiple agent benchmarks. Utility scores and factual credibility are different objects; this project need not first adopt a full reinforcement-learning platform.

Research snapshot: 2026-10-23. These conclusions guide design revision and validation; they do not claim implementation, superiority to baselines, or biological equivalence. Original evidence, user authorization, source corrections, and deletion constrain all derived memories.
