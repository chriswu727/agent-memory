# Citation coverage at semantic publication

An assertion can accurately summarize a complete source while citing an incomplete subset of that source. The [four-turn longitudinal checkpoint](../evaluations/v1-2026-10-25-longitudinal-publication-failure.json) exposed this distinction: a published summary listed five writing suggestions, but its references omitted the suggestion about the letter's location and physical details. The verifier saw the missing text in complete source context and still approved the reference set.

The `citation-coverage-v1` cognitive input contract adds a separate required `citation_coverage_verdict` for claims, current-situation updates and belief links. The runtime constructs each proposal's `citation_scope` from its own references. Positive support is limited to that proposal's numbered supporting excerpts; an abstraction additionally limits support to the excerpts selected as relevant. The coverage target is the entire proposal, including attribution, conditions, negation, uncertainty, world, time, procedural outcomes and the asserted relationship.

Complete source records remain available to detect qualifications and counterevidence. Under `citation-coverage-v1`, they cannot fill a missing positive premise. Other proposals cannot lend their citations to the current proposal, including an episode whose authorized member evidence covers an entire message. Episode organization retains its existing complete-member authority and fidelity checks.

The successor `citation-provenance-v1` clarifies a narrow attribution permission. A quotation's text does not itself identify which recorded role supplied it. For each selected positive reference, the server-derived `provenance_authority` permits only that reference's own source `observed.actor_role` and `observed.delivery_state` to support recorded speaker role and communication status. The verifier must resolve the exact event ID, revision and content hash, including when a bounded request stores the source once and supplies a `source_ref`. This permission applies to the same selected indices as excerpt support; excluded, irrelevant and counterexample references cannot lend their provenance.

These two fields do not establish a human identity, the truth or completion of an external event, fulfillment of a promise, or any uncited source text. Other metadata fields provide no positive premise under this exception. Uncited content and other proposals retain their counterevidence-only role. Source eligibility, world, current-request and episode-fidelity constraints remain unchanged.

Coverage approval is required independently of the existing whole-proposal, per-reference, request, relationship and instance checks. Missing coverage assessments fail schema validation; unknown or contradictory coverage prevents acceptance. Publication checks the assessment again. A positive coverage verdict cannot override a failed context or fidelity check. This adds no model call or spending allowance.

Fresh jobs continue to use `citation-provenance-v1`. The explicitly selected experimental `shared-verification-sources-v1` contract inherits its authority rules and puts each complete source record once in `verification_sources` for general/orientation verification, with exact event/version references from each numbered citation. The projection validates hashes, spans and excerpts and rejects conflicting records for the same source version. Bounded local/history modes retain their existing shared contexts. All original source content, qualifications, counterevidence and proposal-specific citation indices remain available; deduplication adds no inference authority or model call.

Lossless representation does not establish equivalent model judgment. A [paired real-model diagnostic](../evaluations/v1-2026-10-25-memory-efficiency.md) reduced input tokens but exposed an unsupported citation-coverage approval in a supplementary pronoun/name case. Default promotion was rejected; the contract remains available for explicit experiments and replay.

Previously frozen jobs retain their recorded input version, including the exact `citation-coverage-v1` and `citation-provenance-v1` messages, payloads and response schemas. Existing stored memories are not silently reverified or rewritten. These contracts inherit the prior history-link accounting and episode/source semantics. Compatibility with a prior contract is not evidence that an old failed publication has become valid.

Citation coverage is a fallible model judgment. Structural validation and an independent verdict improve the boundary but cannot prove arbitrary language entailment. The provenance clarification has deterministic regression coverage for request scope, source guards, publication gates and snapshot compatibility; improved real-model judgment has not been established. Existing frozen longitudinal evidence retains its recorded older contract. Regression tests must distinguish deterministic gate behavior from actual verifier behavior, and a successful bounded diagnostic cannot substitute for the remaining longitudinal evaluation.
