# LoCoMo, 2026-10-29: memBrain plugin path vs full context

Roadmap item A6. First end-to-end answer-accuracy run on a public benchmark.

## Result

LoCoMo (`snap-research/locomo`, `locomo10.json`), all 10 conversations, categories 1 to 4 (1,540 questions). Each arm was answered by `deepseek-flash` (DeepSeek-V4.1-Flash) with thinking disabled, temperature 0, and judged by the same model with Mem0's published judge prompt.

| Arm | Multi-hop (282) | Temporal (321) | Open-domain (96) | Single-hop (841) | Overall |
| --- | --- | --- | --- | --- | --- |
| Full context (`F`) | 72.0% | 70.7% | 58.3% | 91.2% | **81.4%** |
| memBrain plugin path (`M`) | 51.8% | 71.3% | 53.1% | 76.6% | **69.5%** |
| No memory (`N`) | 2.5% | 0.6% | 18.8% | 1.2% | 2.4% |

- memBrain is 11.9 points below full context overall. It sends the host about 11,500 characters per question (session context plus recall), against about 96,000 characters of transcript for full context, roughly one eighth.
- Temporal questions are on par with full context (71.3% vs 70.7%). Every stored message carries its session date, and recall returns whole messages.
- The losses are in single-hop (−14.6 points) and multi-hop (−20.2 points) questions. Multi-hop questions ask for facts gathered across sessions ("Where has Melanie camped?"); recall shows at most eight source messages, and the host searched with `memory_recall` on only 482 of the 1,540 questions.
- Per question: full context was right and memBrain wrong on 292 questions, the reverse on 109; 961 were right in both and 178 wrong in both.
- Per conversation, memBrain scored 64% to 76% and full context 76% to 85%.

## Context from published results

Mem0's paper (arXiv 2504.19413, Table 2) reports overall LLM-as-a-Judge scores with GPT-4o-mini as the answering model:

| System | Overall |
| --- | --- |
| Full context | 72.90% |
| Mem0 with graph | 68.44% |
| Mem0 | 66.88% |
| Zep | 65.99% |
| Best RAG | 60.97% |
| LangMem | 58.10% |
| OpenAI memory | 52.90% |
| A-Mem | 48.38% |

These numbers are **not directly comparable** with ours. The answering model differs (GPT-4o-mini against DeepSeek-V4.1-Flash, which scores 81.4% with full context here against their 72.9%). Their judge is described only as "a separate, more capable LLM", while ours is the answering model. Their memory systems also extract memories with a model at ingestion time. What can be compared is the gap to full context under each setup: Mem0 is 6.0 points below full context in their run, and memBrain is 11.9 points below in ours.

## Method

- **Harness**: `evaluations/locomo/run_locomo.py` at this commit. Raw per-question results (question, gold answer, generated answer, memBrain searches, context size, judge label) are in `evaluations/locomo/results-2026-10-29/`.
- **Answer prompt**: the instructions of Mem0's `ANSWER_PROMPT` (v0.1.100), shared by all arms; answers are under 5 to 6 words.
- **Judge**: Mem0's `ACCURACY_PROMPT` (v0.1.100, Apache-2.0), verbatim, with JSON output.
- **memBrain arm**: one embedded installation per conversation.
  - Every turn was stored as the hooks store a user message: one conversation per LoCoMo session, the session date and speaker prefixed to the text, and image captions appended.
  - The local multilingual embedding model was installed, and questions started only after every message was embedded.
  - Recording was paused before questions.
  - Each question was a new session: the session-start context (notice and history) and per-message recall were injected, and the host could call `memory_recall` up to twice.
  - No notes were saved. Notes are memBrain's main mechanism for durable facts, but they need a host model in the conversation, and LoCoMo is ingested without one.
- **Full-context arm**: the whole dated transcript in the system prompt.
- **No-memory arm**: the question only.

## Cost and incidents

- The run stopped once part way through: the first API key began returning `401` after 699 N, 583 F and 152 M answers. It resumed with a new key. Answers already written were kept, and no question was answered twice.
- The resumed part made 6,926 model calls: 39.6 million prompt tokens, 92.5% of them cache hits, and 91,000 completion tokens. Its cost was 4.75 CNY (account balance 435.50 → 430.75).
- Usage for the first part was not recorded, because the harness then wrote usage only at the end. It now writes after every question. Scaling by the number of answers, the whole run cost about 7 CNY (about one US dollar).
- One installation took longer than the 35-second service start deadline while the machine was busy, and the run stopped. The harness now waits for the service to become ready.

## Limits

- One run with one host model and a same-model judge. No variance estimate.
- The memBrain arm does not use notes, people or typed plans (Phase B), so it measures recording, history and recall only.
- LoCoMo is a conversation between two people, both stored as user messages. memBrain is built for a person talking to an agent.
- Category 5 (adversarial) was not scored, as in Mem0's evaluation.
- Nothing was tuned on these questions. Any change made in response to these results should be checked on a split that is not reported, or on a different benchmark.
