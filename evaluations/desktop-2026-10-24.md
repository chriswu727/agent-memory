# 桌面安装与恢复验收（2026-10-24）

本次验证本机安装、固定大脑身份、后台服务生命周期与接入配置，不评估新的长期记忆算法或模型回答质量。执行环境为 macOS、Python 3.12 和本机 Docker；没有调用付费模型，也没有触发 GitHub CI。

## 交付行为

- `desktop setup` 创建稳定的私有 profile，配置一次认知提供方，准备专属 PostgreSQL/pgvector、迁移和固定大脑，后台启动 API 与 worker。认知模型可以暂时不配置，状态会明确说明。
- 数据库、配置更新和实例生命周期各有独立的锁。重复连接不会重复创建大脑或启动第二个服务；安装中断保留已提交身份，配置损坏或丢失时不生成新身份掩盖问题。
- MCP 配置只包含解释器与 profile 路径；连接时读取本机凭据并自动启动服务。Python `open_client()` 同样绑定固定大脑，无需复制 token、URL、brain ID。
- 就绪检查验证服务身份、认证、实际数据库和大脑、工作线程。配置存在不等于提供方已经验证；MCP 能力仍为 `tools_only`。
- 停止使用认证后的实例控制接口，不根据 PID 杀进程；等待 worker 真正结束再停止数据库，超时保留数据库运行。默认停止不删除数据卷。
- 桌面进程不查找开发仓库 `.env`，本机 HTTP 不使用环境代理。Docker 限于本地端点，并将验证过的端点固定给 Compose 命令。
- 生命周期日志只记录时间、固定事件码和实例 ID，大小有界；记忆内容与 API key 不进入这些日志。

## 验收

真实 Docker 端到端用例位于 `tests/test_desktop_e2e.py`，默认跳过，只有显式设置 `MEMORY_DESKTOP_E2E=1` 才执行。每次创建独立测试安装和数据库；最后只删除该测试自己创建的卷。

用例从含中文和空格的 profile 路径启动，在无关工作目录运行，并故意设置错误的继承数据库地址、API key 和 HTTP 代理。它覆盖：

1. 冷启动完成迁移、API、worker 和唯一大脑初始化。
2. 两个并发连接复用同一个实例。
3. 经真实 HTTP 和 PostgreSQL 执行 `BrainRuntime` 输入、确定性生成、交付与完成，持久保存两条消息。
4. 停止服务并保留数据。
5. 使用生成的无秘密配置，通过真实 MCP stdio 协议自动重新启动服务。
6. 重启后固定大脑与事件 ID 不变；恢复完成轮次不重复生成或交付。
7. 未认证的监控请求被拒绝，生命周期日志不包含测试对话及访问密钥。

源码环境、独立 wheel 安装环境、通过 `uv tool install` 从本地源码 ZIP 安装的隔离工具环境均通过该用例。ZIP 安装使用与 README 相同的命名 URL 安装方式，验收时使用本地归档；并非依赖源码 editable 安装。wheel 中 Python 文件、Compose 模板、全部迁移与契约均逐字节核对过。

独立 wheel 环境第一次运行有一个 pytest 配置警告：该测试环境未安装 pytest-asyncio，却读取了项目的 `asyncio_mode` 设置；用例本身通过。最终隔离工具环境包含该测试依赖，端到端用例通过且没有此警告。

回归期间发现固定大脑的并发插入偶发违反复合唯一约束。原语句仅处理 `id` 冲突，但表还具有 `(tenant_id, owner_id, id)` 唯一约束。改为处理所有唯一冲突后，仍通过原有所有者检查返回大脑；增加 20 轮、每轮 4 个请求的并发回归。跨租户与同租户其他所有者仍无法接管既有大脑。

最终代码的 Python 全量回归为 **2,554 passed、1 skipped**，用时 144.78 秒。唯一默认跳过项是上述需要显式启用 Docker 的桌面端到端用例；它已经在独立工具安装环境另外执行并通过，最终并发冷启动版本用时 9.07 秒。固定大脑数据库测试 11 项单独通过，其中包含 20 轮并发创建。Ruff、diff 检查与 sdist/wheel 构建通过。

## 尚未覆盖

尚无原生桌面安装包，仍需 uv 和可运行的本地 Docker。Windows 路径、ACL 与锁分支以及 Linux 路径已有实现和相应单测，未完成这两种系统的实机端到端验收。

没有自动修改外部 Agent 的配置，也没有为某个具体宿主实现消息、推理前上下文、交付和 compact 的完整生命周期适配。MCP 连接本身仍不能自动获得全部聊天。提供方凭据的可用性、真实语义学习质量、长期运行负载均不是本次安装验收的结论。

本机服务身份握手可防止把访问凭据直接发送给静态占用端口的外来服务；它不提供 TLS，也不承诺消除本机恶意程序在握手后接管端口的全部竞态。
